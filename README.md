# El sistema universitario español, disperso

## El problema

La información del sistema universitario español se encuentra fragmentada en decenas de fuentes diferentes, lo que dificulta que los estudiantes puedan acceder a ella y tomar decisiones informadas sobre su futuro académico.
Funcionalidades principales

- Directorios por comunidad autónoma con mapas interactivos.
- Rankings internacionales explicados y comparados.
- Guías editoriales para cada etapa del proceso universitario.
- Fichas detalladas de cada institución.

---

## Tecnologías utilizadas

El proyecto está desarrollado utilizando tecnologías web nativas, sin recurrir a frameworks externos.

| Tecnología | Aplicación |
|---|---|
| HTML5 | Estructura semántica y organización del contenido. |
| CSS3 | Estilos, diseño visual y adaptación responsive. |
| JavaScript | Interactividad y funcionalidades dinámicas. |

### Características técnicas

- **CSS Custom Properties:** centralización y reutilización de variables de diseño.
- **Flexbox y CSS Grid:** organización de los elementos y creación de layouts adaptables.
- **Responsive Design:** adaptación de la interfaz a diferentes dispositivos y resoluciones.
- **Metodología BEM:** organización y nomenclatura de las clases CSS.
- **JavaScript IIFE:** encapsulación de la funcionalidad para evitar la contaminación del ámbito global.

##  Herramientas utilizadas

### Visual Studio Code
Entorno de desarrollo principal. Se han utilizado diferentes extensiones para optimizar el flujo de trabajo:

- Live Server: visualización del proyecto en tiempo real.
- BEM Helper: apoyo en la aplicación de la metodología BEM.
- px to rem: conversión de unidades para facilitar la escalabilidad.
- W3C Web Validator: validación del código.
- Error Lens: detección y visualización de errores.
- Herramientas de autocompletado y edición HTML.

### Figma
Herramienta utilizada para el diseño integral del proyecto, incluyendo la definición de la identidad visual, los diseños responsive y el sistema de diseño.

También se han preparado y exportado los recursos gráficos optimizados para su posterior integración en el desarrollo.

### Unsplash
Fuente de recursos visuales utilizada para incorporar imágenes representativas y enriquecer la experiencia visual de la plataforma.

### Claude
Herramienta de inteligencia artificial utilizada como apoyo en la revisión y mejora de los comentarios del código, facilitando su comprensión y legibilidad.
